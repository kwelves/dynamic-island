**Порядок справа (как в Windows 11):** стрелка трея ^ · значки трея · Раскладка · [Wi‑Fi · Звук · Батарея+%] · Дата. Wi‑Fi, звук и батарея — одна кнопка-группа «Быстрые настройки» (ниже). Bluetooth в баре нет — он в быстрых настройках. **Слева:** логотип · имя приложения (`bar-app`) · меню приложения (`bar-menu`) · погода.

**Hit-test:** вся коробка пункта на полную высоту бара (0…32), не только плашка. Нажатие — по `WM_LBUTTONDOWN`, не по отпусканию (как в macOS).

|---|---|---|---|---|

| Музыка | 300 × 32 | 10 | 8 (только в Glass) | обложка слева, время по центру, визуализатор справа |

Высота H считается **от верха экрана**. В Solid остров уходит ниже бара только в «Уведомлении» и «Плеере» (на 72 и 158 px).

### Геометрия оболочки (Direct2D `ID2D1PathGeometry`)

```
y0    = Solid ? barHeight : 0          // линия, из которой «вытекает» остров
avail = H − y0                         // если ≤ 0 — не рисуем (остров слит с баром)
e     = min(radiusEar, avail / 2)
r     = min(radiusBottom, W / 2, avail − e)
L = cx − W/2,  R = cx + W/2

BeginFigure (L − e, y0)
  ArcSegment → (L, y0 + e)       radius e, CLOCKWISE,         SMALL   // вогнутое «ушко»
  Line      → (L, H − r)
  ArcSegment → (L + r, H)        radius r, COUNTER_CLOCKWISE, SMALL
  Line      → (R − r, H)
  ArcSegment → (R, H − r)        radius r, COUNTER_CLOCKWISE, SMALL
  Line      → (R, y0 + e)
  ArcSegment → (R + e, y0)       radius e, CLOCKWISE,         SMALL
EndFigure CLOSED
```

Все четыре параметра (W, H, r, e) анимируются одной пружиной, поэтому форма всегда согласована. Контент клипуется прямоугольником L…R × 0…H со скруглением r снизу.

## Положение панели и меню

```
y = barHeight + panel-gap (32 + 6 = 38)
x = clamp(item.left, panel-margin, screenW − panelW − panel-margin)    // левый край панели = левый край плашки пункта
transformOrigin = (item.centerX − x, 0)                                // масштаб «из иконки»
```

Окна: `WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE | WS_EX_TOPMOST`, DirectComposition-визуал с backdrop. Бар — AppBar (`SHAppBarMessage ABM_NEW`, `ABE_TOP`, высота 32); остров — отдельный слой поверх бара того же окна, чтобы морф был в одном кадре.

## Порядок слоёв (снизу вверх)

1. Бар (`bar-bg` / стекло) · 2. Плашка подсветки · 3. Плашки бара · 4. Остров (оболочка + контент) · 5. Панели и меню.
