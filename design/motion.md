# Motion

Всё движение — пружины. Цифры заданы как в SwiftUI (`response`, `dampingFraction`) и переведены в stiffness/damping для массы 1. Прерываемость обязательна: новая цель подхватывает **текущие** позицию и скорость, ничего не сбрасывается в ноль.

## Формулы и интегратор

```
ω0        = 2π / response
stiffness = m · ω0²                    (m = 1)
damping   = 2 · ζ · ω0 · m = 4π·ζ / response
bounce    = 1 − ζ                      (SwiftUI .spring(duration: response, bounce:))
перелёт   = exp(−π·ζ / √(1 − ζ²))      (для ζ < 1)
```

```cpp
struct Spring {
    float x = 0, v = 0, target = 0, k = 0, c = 0;
    void set(float response, float zeta) { float w = 6.2831853f / response; k = w * w; c = 2.f * zeta * w; }
    void step(float dt) {                       // dt в секундах
        int n = (int)ceilf(dt / 0.002f); float h = dt / n;   // подшаг ≤ 2 мс
        for (int i = 0; i < n; ++i) { float a = -k * (x - target) - c * v; v += a * h; x += v * h; }
    }
    bool settled() const { return fabsf(x - target) < 0.01f && fabsf(v) < 0.1f; }
};
```

Кадр — по `DCompositionWaitForCompositorClock` / `DwmFlush`, dt = реальное время кадра (≤ 50 мс). На 120/144 Гц пружины выглядят так же — они от времени, а не от кадров.

## Последовательности

Правило морфа острова: **оболочка (W, H, радиусы) — одна пружина**, контент — отдельно. При росте оболочка стартует сразу, контент заходит через 70 мс. При сжатии сначала уходит контент (120 мс), через 40 мс сжимается оболочка.

### Menu tracking — переключение на соседний пункт

| Условие | Поведение |
|---|---|
| Панель открыта, курсор вошёл в коробку другого пункта бара | старая панель исчезает, новая появляется **в том же кадре**, без fade и масштаба (0 мс) |
| Плашка подсветки | перепрыгивает мгновенно (macOS). Опция `highlight.slide` `highlight.slide` (0.25 / 1.00) — переезд x и ширины |
| ← / → с клавиатуры при открытой панели | то же, по порядку видимых пунктов |
| Курсор ушёл с бара | ничего не меняется — панель остаётся открытой до клика/Esc |
| Пункт спрятан под островом | в трекинге не участвует |

### Разъезд бокового контента бара

1. Каждый кадр берётся текущая (анимируемая) ширина оболочки: `L = cx − W/2`, `R = cx + W/2`.
2. Плашка прячется, если её коробка пересекает `[L − 12, R + 12]`.
3. Спрятать: opacity 1 → 0, translateX 0 → −6 (левые) / +6 (правые), scale 1 → 0.9 — `bar.items` (0.30 / 1.00), без задержки. Hit-test выключается сразу.
4. Вернуть: обратная анимация той же пружиной, каскад 25 мс на каждые 40 px от острова (максимум 100 мс).
5. Остальные плашки **не сдвигаются** — группы прижаты к краям экрана, как в macOS у выреза.

## Уменьшить движение

Если в Windows выключены анимации (`SystemParametersInfo(SPI_GETCLIENTAREAANIMATION) == FALSE`): все ζ < 1 → 1.0 с тем же response; blur контента → 0; масштаб панели → только fade; визуализатор стоит.
