# Dynamic Island TopBar — правила и состояние проекта

## Цель

Форк Windhawk-мода «Dynamic Island for Windows» (MIT). Плавающая «таблетка» превращена в верхний бар на всю ширину экрана, как menu bar в macOS на MacBook с вырезом.

- Бар зарегистрирован как AppBar (`SHAppBarMessage`, `ABE_TOP`).
- Остров стоит в центре бара и выглядит как вырез.
- По бокам бара: слева логотип, активное приложение и погода; справа Bluetooth, Wi‑Fi, звук, батарея, раскладка и дата.
- По клику на пункт открываются панели и меню.

Все прежние функции мода остаются рабочими: анимации, морф, раскрытие, визуализатор, медиа, погода, мониторинг.

## Как работать (правила пользователя)

- Пиши по-русски, простыми словами.
- **Главная цель — «winOS».** Всё, что умеет панель задач Windows, работает сверху в баре. Поведение 1 в 1 как в Windows, внешний вид и анимации как в macOS (стекло, bounce, morph, пружины из `design/`). Пользователь — перфекционист. Для каждой функции:
  1. сначала расписать, как она ведёт себя в Windows во всех случаях: клики, наведение, клавиатура, переходы между пунктами, что закрывается и когда;
  2. сделать так же;
  3. проверить самому на экране. Если для проверки нужны клики — спросить, пользователь отойдёт от компьютера. Без разрешения на экране ничего не нажимать.
- Работай маленькими шагами. После каждого рабочего шага:
  1. собрать обе разрядности компилятором Windhawk без ошибок и предупреждений;
  2. закоммитить и запушить в `origin` (ветка `topbar`);
  3. объяснить, как проверить;
  4. ждать «ок» и только потом браться за следующий шаг.
- Все размеры, цвета, радиусы, шрифты и пружины берутся **только** из `design/`:
  - `design-tokens.json`;
  - `components.md`;
  - `motion.md`;
  - `prototype.html`.

  Каждое отступление от дизайна перечисляй в отчёте.
- Реестр, политики, настройки Windows и настройки других модов **не трогать без «да»**. Исследования только читают.
- Меню приложений («Файл / Правка / Вид» из прототипа) **не делать**.
- Автоматическое «Не беспокоить» не нужно.

## Сборка и установка

```powershell
pwsh -File .\deploy.ps1                # собрать оба мода (32 и 64 бит), поставить в Windhawk, перезапустить
pwsh -File .\deploy.ps1 -Mod topbar    # только бар (или -Mod tray — только мост)
pwsh -File .\deploy.ps1 -BuildOnly     # только собрать
```

Предупреждения `deploy.ps1` не показывает. Проверка: `clang++ -fsyntax-only` с теми же флагами для `x86_64-w64-mingw32` и `i686-w64-mingw32`.

## Устройство кода (главное)

- **`namespace Design`** — все токены из `design/`: размеры, цвета, пружины, твины, глифы Segoe Fluent Icons, стили текста. Новые значения добавлять только сюда, с именем токена в комментарии.
- **`namespace DesignType`** — шрифты Segoe UI Variable Text/Small и текстовые раскладки по стилям дизайна.
- **`namespace BarStatus`** — фоновый поток с данными для бара: приложение, Bluetooth, сеть, громкость, батарея, раскладка, дата.
- **`namespace BarContent`** — отрисовка пунктов бара.
- **`namespace TopBar`** — окно бара, AppBar, прятанье пунктов рядом с островом (пружина `bar.items`), плашка подсветки. Wi‑Fi, звук и батарея — кнопка-группа быстрых настроек (`BarContent::IsQuick`, `PlateBox`): одна плашка на наведение и открытую панель, колесо над звуком (`Panels::WheelVolume`, 2 % за щелчок), правый клик по отпусканию — меню значка (`Panels::ContextMenu`, `g.context`).
- **`namespace BarTip`** — подсказки над сетью, звуком и батареей: своё слоистое окно, задержка = время двойного щелчка, тексты Windows (ресурсы `SystemTray`, `NetworkIcon`), тикает из `Panels::Tick`.
- **`namespace Panels`** — все панели и меню по клику:
  - одно окно `WS_EX_LAYERED | TOOLWINDOW | NOACTIVATE | TOPMOST`, Direct2D;
  - рабочий поток для Bluetooth, Wi‑Fi, радио и замера энергопотребления;
  - поток с low-level хуками мыши и клавиатуры только пока панель открыта: Esc, клик мимо, ← / →, ↑ / ↓ / Enter в меню;
  - там же `SetWinEventHook(EVENT_SYSTEM_FOREGROUND)`: смена активного окна (Alt+Tab, Win, Win+D) закрывает панель; первые 300 мс после открытия не считаются;
  - **`Material`** — стекло по `materials.panel`: снимок экрана в ¼ размера (фоновый поток снимает его заранее, пока курсор на баре, не чаще раза в 0,4 с; без свежего снимка — сразу при открытии), размытие σ30/4 на CPU (три box-прохода), насыщенность 1.8, заливка `panel-bg` 0.40, над светлым фоном до `readableAlpha` 0.70; при отрисовке растягивается обратно с линейной интерполяцией. Через ~1,5 с после запуска одна панель и одно меню рисуются невидимо (прогрев шрифтов и Direct2D). Служебный пакет `kTimings` пишет разбивку последнего открытия в `%TEMP%`;
  - клик по бару при открытом «Пуске», быстрых настройках или центре уведомлений: мод нажимает Esc (`SetForegroundWindow` Windows при «Пуске» запрещает) и открывает панель, когда системное окно спрятано.
- **`namespace Tray`** — значки программ из трея. Мост в Explorer ловит `WM_COPYDATA` (`dwData = 1`) к `Shell_TrayWnd` хуком `WH_CALLWNDPROC` (только чтение), растеризует значок сразу и шлёт пакет (`'DITR'`, формат `Packet` одинаковый в обоих файлах) в окно бара из своего потока. Бар при старте и на «hello» моста рассылает `TaskbarCreated`, чтобы программы заново прислали значки; свою рассылку бар игнорирует. Пакет `kQuery` возвращает счётчики для тестов. Каждый значок — отдельный пункт со своей пружиной `bar.items`; не помещающиеся справа от острова в покое не показываются.
- **Вырез:** блок «Bar notch (design/components.md "Вырез")» в цикле отрисовки, `DrawNotchShell`, `DrawNotchTime`, `DrawVizBars`, `DrawNotchNotification`, `DrawDesignPlayer`.

## Что осталось

1. **Этап W1 «Быстрые настройки»** — спецификация в разделе «winOS» одобрена (8 нояб. 2026). Шаг (а) сделан, ждёт проверки кликами и «ок». Временно до шага (б): клик по значку группы открывает его прежнюю панель (Wi‑Fi, «Звук», «Батарея»); панель Bluetooth из бара недоступна.
2. **Док** — этап «Док» плана, ещё не выбран. **Спрятать панель задач Windows** — этап W5, только когда док готов.
3. **Анимации из `motion.md`** (этап W7):
   - контент острова входит через 70 мс после роста оболочки и уходит за 120 мс (`island.content.out`) перед сжатием;
   - каскад строк 20 мс;
   - `island.art`;
   - таймер уведомления (4000 мс) замирает при наведении;
   - «Уменьшить движение» (`SPI_GETCLIENTAREAANIMATION`).

Сделано и проверено: стекло панелей (снимок заранее, открытие 10–16 мс), закрытие панелей при смене окна и при «Пуске», трей в баре (мост в Explorer, «Другие значки» Windows, меню-стрелка, клики, меню программ, окна программ под баром), погода — панель, имя приложения по настройке (по умолчанию выкл.).

### Быстрые настройки (W1): спецификация

Значения с пометкой **«решение»** — наши, их не было в `design/`. Они одобрены и записаны в `design/design-tokens.json` (`source: решение`), `design/components.md` («Быстрые настройки») и в `namespace Design` с пометкой «наше решение».

#### 1. Кнопка-группа в баре

- Wi‑Fi (или Ethernet / нет сети), звук и батарея с % — **один пункт бара**. Коробки внутри — как сейчас: 8 + 16 + 8, зазор `bar-status-gap` 2, батарея «87%» + 5 + глиф 20.
- Отдельный пункт Bluetooth из бара убирается: Bluetooth переезжает в быстрые настройки.
- Порядок справа, как в Windows 11: ^ · значки трея · раскладка · **[Wi‑Fi звук батарея]** · дата. Стрелка ^ слева от значков (так в Windows 11 и уже так в баре). На экране не сверено: панель задач на этом ПК автоскрытая, PrintWindow её XAML не снимает; сверить при первом тесте кликами.
- Наведение: одна плашка `bar-highlight` на всю группу (y = 4, высота 24, радиус 6), как в Windows подсвечивается вся группа.
- Подсказки: через 500 мс наведения (время двойного клика, как у подсказок Windows) под значком появляется подсказка своей иконки; переход на соседнюю иконку меняет подсказку сразу; клик, колесо или уход курсора её прячет. Текст как в Windows:
  - сеть: имя сети и «Доступ в Интернет» / «Нет доступа к Интернету»; без сети — «Нет подключения к Интернету»;
  - звук: «Динамики (имя устройства): 45 %»; без звука — «… : без звука»;
  - батарея: «Батарея: 87 % осталось (3 ч 12 мин)», на зарядке — «… заряжается». Точные формулировки сверю с этим ПК на экране.
- Вид подсказки **(решение)**: фон `panel-bg-solid`, обводка `panel-rim` 1 px, радиус 6 (`radius-menu-row`), поля 8 × 4, текст `panel-caption` 11/14 `ink-1`, верх = низ бара + `panel-gap` 6, по центру значка, не выходит за экран; появляется `panel.fade`.
- Колесо над значком звука: ±2 % за щелчок (у тачпада — пропорционально), всплывашка громкости острова как при клавишах громкости. Над сетью и батареей колесо ничего не делает.
- Левый клик по любой части группы открывает/закрывает быстрые настройки (по `WM_LBUTTONDOWN`, как остальные пункты бара).
- Правый клик — меню своей иконки, как в Windows (точные формулировки сверить на экране):
  - сеть: «Диагностика неполадок», «Параметры сети и Интернета»;
  - звук: «Открыть микшер громкости», «Параметры звука», «Устранение неполадок со звуком»;
  - батарея: «Параметры питания и спящего режима».
- Открытие — морф: плашка группы (ширина группы × 24, радиус 6) растёт в панель (ширина × высота, радиус 16). Прямоугольник и радиус — одна пружина `panel.open` (0.34 / 0.80, перелёт 1.5 %), прозрачность — `panel.fade`, содержимое входит через 70 мс пружиной `island.content` (opacity 0 → 1, y +6 → 0). Закрытие — тот же морф обратно в плашку пружиной `island.collapse` (0.42 / 0.92), без отскока; содержимое сначала уходит за 120 мс (`island.content.out`). **(решение: это вместо обычного открытия панелей scale 0.94 → 1.)**
- Положение: по правилу `components.md` (левый край = левый край плашки, прижать к краю экрана с полем `panel-margin` 8). Группа справа, поэтому панель почти всегда прижата к правому краю. При смене высоты верх стоит на месте, растёт низ.

#### 3. Внутренние страницы (морф)

- Одно окно без постоянного размера. Ширина у всех страниц одна (316), поэтому меняется в основном высота; если страница шире — меняется и ширина.
- Вперёд: плитка «вырастает» в заголовок «‹ Название [переключатель]» (высота `panel-header-h` 38, кнопка «назад» 28 × 28 радиус 8 с отражённым `chevron-right` **(решение)**). Новое содержимое входит через 70 мс пружиной `island.content` (в `design/` нет имени `island.content.in` — это оно: задержка 70 мс + `island.content`).
- Назад — то же обратно, рамка `island.collapse` (0.42 / 0.92), без отскока.
- Клик посреди анимации: все пружины продолжают с текущих значений и скорости (правило `motion.md`), без рывка.

- Стекло: снимок и размытие готовятся сразу под самый большой размер (316 × до 560) **(решение)**, при росте окна только меняется видимая часть.

Высота страницы — до 560 или до низа рабочей области.

#### 5. Как это сделать технически (исследование только читает)

| Что | Как | Нужно «да»? |
|---|---|---|
| Wi‑Fi, Bluetooth вкл/выкл | `Windows.Devices.Radios` (уже в коде) | нет |
| Яркость | чтение — `IOCTL_VIDEO_QUERY_DISPLAY_BRIGHTNESS` (уже в коде), запись — WMI `WmiSetBrightness` (так делает ползунок Windows) | нет: это и есть функция ползунка |

| Режим «в самолёте» | недокументированный COM `IRadioManager` (им пользуется сама Windows) | сначала исследование (только чтение), показать владельцу |
| Энергосбережение | состояние — `GetSystemPowerStatus` / уведомление питания; включение — исследовать | **да**: сначала показать способ владельцу и ждать «да» |

## Тесты на экране

Клики только с разрешения пользователя. Активным делается своё окно-«приёмник», Esc отправляется прямо в окна меню (`PostMessage`), а не глобальным нажатием: иначе он попадает в терминал с Claude Code. Служебные пакеты бару (`WM_COPYDATA`, `'DITR'`): `kQuery`, `kDump` (список значков трея в `%TEMP%`), `kTimings` (время открытия панели в `%TEMP%`).

## Известные отступления от дизайна

- Тень панелей нарисована слоями, без настоящего размытия.
- Стекло панелей — снимок экрана в момент открытия: если под открытой панелью что-то меняется (видео, прокрутка), размытие не обновляется. «Живое» стекло решили не делать.
- Стекло считается на CPU, а не эффектами Direct2D; у края монитора крайние пиксели повторяются вместо `BORDER_MODE_HARD`.
- Если при клике по бару был открыт «Пуск» или системная панель Windows, наша панель появляется с задержкой до 0,5 с, пока они прячутся.
- Bluetooth: клик по устройству открывает настройки, а не подключает его.
- «Батарея»: «Значительное энергопотребление» — приложения с окном, которые за 1,5 с заняли не меньше 2,5 % всех ядер процессора; показываются значки самих приложений.
- Календаря в дизайне нет. Он собран из токенов панели: недели по 28, круг «сегодня» 26, стрелка «назад» — отражённый `chevron-right`.
- Погода — панель, а не меню: вкладка погоды из выреза при включённом баре убрана и перенесена сюда. Крупная температура (34/40, Light, tnum), глиф условия 28 и высота строки 62 — значений в `design/` нет. Ветер, «ощущается» и влажность — строки «название — значение» без значков (глифов ветра и влажности в токенах нет). Описание погоды приходит на языке интерфейса (`lang=` у wttr.in), город переводится на язык интерфейса геокодером Open‑Meteo (уходит только название города, один запрос на город за сеанс), иначе — как отдаёт wttr.in.
- Кнопка-группа: плашка наведения — тот же `bar-highlight`, что под открытой панелью, и появляется сразу (в Windows наведение светлее нажатия; в дизайне один токен). Подсказка «без звука» — перевод острова «Без звука» (у Windows 11: «Звук отключен», у старого трея: «без звука»). Порядок пунктов в меню правого клика взят из порядка ключей `SystemTray.dll`, на экране не сверен. Подсказка сети не знает о режиме «в самолёте» (ждёт исследования).
- Трей: значки программ цветные (в macOS одноцветные); выбранная строка меню-стрелки — `row-hover`; стрелка — повёрнутый `chevron-right`; клик по пункту, открытому наведением меньше 0,5 с назад, его не закрывает.
- Логотип открывает меню вместо «Пуска». Пункта «Недавние объекты» нет. Перезагрузка, выключение и выход открывают окно Windows «Завершение работы».
- Погода: дождь, снег и туман показываются глифом облака. Ethernet — глиф E839, его нет в токенах.
- Новые надписи переведены только на русский (остальные языки — английский).
