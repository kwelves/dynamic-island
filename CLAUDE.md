# Dynamic Island TopBar — правила и состояние проекта

## Цель

Форк Windhawk-мода «Dynamic Island for Windows» (MIT). Плавающая «таблетка» превращена в верхний бар на всю ширину экрана, как menu bar в macOS на MacBook с вырезом.

- Бар зарегистрирован как AppBar (`SHAppBarMessage`, `ABE_TOP`).
- Остров стоит в центре бара и выглядит как вырез.
- По бокам бара: слева логотип, активное приложение и погода; справа Bluetooth, Wi‑Fi, звук, батарея, раскладка и дата.
- По клику на пункт открываются панели и меню.

Все прежние функции мода остаются рабочими: анимации, морф, раскрытие, визуализатор, медиа, погода, мониторинг.

## Как работать (правила пользователя)

- Пиши по-русски, простыми словами.
- **Главная цель — «winOS».** Всё, что умеет панель задач Windows, работает сверху в баре. Поведение 1 в 1 как в Windows, внешний вид и анимации как в macOS (стекло, bounce, morph, пружины из `design/`). Пользователь — перфекционист. Для каждой функции:
  1. сначала расписать, как она ведёт себя в Windows во всех случаях: клики, наведение, клавиатура, переходы между пунктами, что закрывается и когда;
  2. сделать так же;
  3. проверить самому на экране. Если для проверки нужны клики — спросить, пользователь отойдёт от компьютера. Без разрешения на экране ничего не нажимать.
- Работай маленькими шагами. После каждого рабочего шага:
  1. собрать обе разрядности компилятором Windhawk без ошибок и предупреждений;
  2. закоммитить и запушить в `origin` (ветка `topbar`);
  3. объяснить, как проверить;
  4. ждать «ок» и только потом браться за следующий шаг.
- Все размеры, цвета, радиусы, шрифты и пружины берутся **только** из `design/`:
  - `design-tokens.json`;
  - `components.md`;
  - `motion.md`;
  - `prototype.html`.

  Каждое отступление от дизайна перечисляй в отчёте.
- Реестр, политики, настройки Windows и настройки других модов **не трогать без «да»**. Исследования только читают.
- Меню приложений («Файл / Правка / Вид» из прототипа) **не делать**.
- Автоматическое «Не беспокоить» не нужно.

## Сборка и установка

```powershell
pwsh -File .\deploy.ps1                # собрать оба мода (32 и 64 бит), поставить в Windhawk, перезапустить
pwsh -File .\deploy.ps1 -Mod topbar    # только бар (или -Mod tray — только мост)
pwsh -File .\deploy.ps1 -BuildOnly     # только собрать
```

Предупреждения `deploy.ps1` не показывает. Проверка: `clang++ -fsyntax-only` с теми же флагами для `x86_64-w64-mingw32` и `i686-w64-mingw32`.

## Устройство кода (главное)

- **`namespace Design`** — все токены из `design/`: размеры, цвета, пружины, твины, глифы Segoe Fluent Icons, стили текста. Новые значения добавлять только сюда, с именем токена в комментарии.
- **`namespace DesignType`** — шрифты Segoe UI Variable Text/Small и текстовые раскладки по стилям дизайна.
- **`namespace BarStatus`** — фоновый поток с данными для бара: приложение, Bluetooth, сеть, громкость, батарея, раскладка, дата.
- **`namespace BarContent`** — отрисовка пунктов бара.
- **`namespace TopBar`** — окно бара, AppBar, прятанье пунктов рядом с островом (пружина `bar.items`), плашка подсветки.
- **`namespace Panels`** — все панели и меню по клику:
  - одно окно `WS_EX_LAYERED | TOOLWINDOW | NOACTIVATE | TOPMOST`, Direct2D;
  - рабочий поток для Bluetooth, Wi‑Fi, радио и замера энергопотребления;
  - поток с low-level хуками мыши и клавиатуры только пока панель открыта: Esc, клик мимо, ← / →, ↑ / ↓ / Enter в меню;
  - там же `SetWinEventHook(EVENT_SYSTEM_FOREGROUND)`: смена активного окна (Alt+Tab, Win, Win+D) закрывает панель; первые 300 мс после открытия не считаются;
  - **`Material`** — стекло по `materials.panel`: перед показом снимается монитор, область под панелью размывается на CPU (σ30, три box-прохода), насыщенность 1.8, заливка `panel-bg` 0.40, над светлым фоном заливка уплотняется до `readableAlpha` 0.70;
  - клик по бару при открытом «Пуске», быстрых настройках или центре уведомлений: мод нажимает Esc (`SetForegroundWindow` Windows при «Пуске» запрещает) и открывает панель, когда системное окно спрятано.
- **`namespace Tray`** — значки программ из трея. Мост в Explorer ловит `WM_COPYDATA` (`dwData = 1`) к `Shell_TrayWnd` хуком `WH_CALLWNDPROC` (только чтение), растеризует значок сразу и шлёт пакет (`'DITR'`, формат `Packet` одинаковый в обоих файлах) в окно бара из своего потока. Бар при старте и на «hello» моста рассылает `TaskbarCreated`, чтобы программы заново прислали значки; свою рассылку бар игнорирует. Пакет `kQuery` возвращает счётчики для тестов. Каждый значок — отдельный пункт со своей пружиной `bar.items`; не помещающиеся справа от острова в покое не показываются.
- **Вырез:** блок «Bar notch (design/components.md "Вырез")» в цикле отрисовки, `DrawNotchShell`, `DrawNotchTime`, `DrawVizBars`, `DrawNotchNotification`, `DrawDesignPlayer`.

## Что осталось

1. **Трей в баре справа** (выбран вариант «маленький мод внутри Explorer»: только подслушивает сообщения трея и копирует значки в бар). Частями: сначала показ значков, потом клики левой и правой кнопкой.
2. **Спрятать панель задач Windows** — только после того, как трей в баре заработает. Внизу останется док Seelen UI (позже, только док; его верхняя панель и её трей будут выключены).
3. **Анимации из `motion.md`:**
   - контент острова входит через 70 мс после роста оболочки и уходит за 120 мс (`island.content.out`) перед сжатием;
   - каскад строк 20 мс;
   - `island.art`;
   - таймер уведомления (4000 мс) замирает при наведении;
   - «Уменьшить движение» (`SPI_GETCLIENTAREAANIMATION`).

## Известные отступления от дизайна

- Тень панелей нарисована слоями, без настоящего размытия.
- Стекло панелей — снимок экрана в момент открытия: если под открытой панелью что-то меняется (видео, прокрутка), размытие не обновляется. «Живое» стекло решили не делать.
- Стекло считается на CPU, а не эффектами Direct2D; у края монитора крайние пиксели повторяются вместо `BORDER_MODE_HARD`.
- Если при клике по бару был открыт «Пуск» или системная панель Windows, наша панель появляется с задержкой до 0,5 с, пока они прячутся.
- Bluetooth: клик по устройству открывает настройки, а не подключает его.
- «Батарея»: «Значительное энергопотребление» — приложения с окном, которые за 1,5 с заняли не меньше 2,5 % всех ядер процессора; показываются значки самих приложений.
- Календаря в дизайне нет. Он собран из токенов панели: недели по 28, круг «сегодня» 26, стрелка «назад» — отражённый `chevron-right`.
- Меню погоды: вторая строка — «ощущается как» и влажность, потому что прогноза на завтра у мода нет.
- Логотип открывает меню вместо «Пуска». Пункта «Недавние объекты» нет. Перезагрузка, выключение и выход открывают окно Windows «Завершение работы».
- Погода: дождь, снег и туман показываются глифом облака. Ethernet — глиф E839, его нет в токенах.
- Новые надписи переведены только на русский (остальные языки — английский).
